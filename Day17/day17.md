# Day 17 – Vehicle Cost Analysis Dashboard

## Objective

Build an interactive Vehicle Cost Analysis Dashboard using Claude AI.

## Process

1. Downloaded the provided CSV dataset
2. Updated the prompt with vehicle details
3. Uploaded the CSV file into Claude
4. Generated an HTML dashboard
5. Reviewed KPIs, fuel comparisons, maintenance costs, and environmental impact
6. Tested the dashboard and captured screenshots

## Features

* KPI Cards
* Fuel Cost Comparison
* Maintenance Cost Analysis
* Environmental Impact Analysis
* E85 Break-even Calculations
* Interactive Charts and Gauges

## Files Included

* vehicle_cost_dashboard.html
* Dashboard screenshots

## Key Learnings

* AI-assisted dashboard creation
* Vehicle cost analysis
* Fuel economy comparison
* Environmental impact visualization
