# Day 16 – Claude Custom Skill: Stock Fundamental Research

## Objective

Create and test a reusable Claude Custom Skill for stock fundamental analysis.

## Process

1. Created a custom skill named **stock-fundamental-research**
2. Added the provided description and instructions
3. Saved the skill
4. Tested it using a stock (e.g., TCS, Infosys, Reliance)
5. Reviewed the generated report and analysis

## Features

* Fundamental analysis
* Valuation metrics
* Ownership trends
* Risk assessment
* Company comparison
* Reusable workflow

## Files Included

* Screenshots of the custom skill
* Generated stock report
* Charts and analysis

## Key Learnings

* Creating reusable AI workflows
* Understanding stock fundamental analysis
* Analyzing valuation and ownership trends
* Saving time with Custom Skills
