# Day 11 – ATS Resume Optimization

## Objective

Optimize a resume for a target job description using Claude AI.

## Process

1. Uploaded resume
2. Added target Job Description
3. Ran ATS Resume Optimizer prompt
4. Reviewed ATS Match Score
5. Analyzed keyword gaps
6. Generated an optimized resume

## ATS Analysis

* ATS Match Score reviewed
* Missing keywords identified
* Resume improvements suggested

## Files Included

* ATS analysis screenshots
* Optimized resume
* Job description

## Key Learnings

* Understanding ATS systems
* Resume keyword optimization
* Tailoring resumes for specific roles
* Improving resume-job alignment
