# Day 18 – Brain Dump Action Planner Skill

## Objective

Create a reusable Custom Skill in Claude to convert raw notes into structured action plans.

## Process

* Created a custom skill named **brain-dump-action-planner**
* Added description and instructions
* Saved and tested the skill with multiple note formats
* Generated structured outputs like summaries, action items, risks, blockers, and open questions
* Verified reusability without re-entering prompts

## Key Outputs

* Structured meeting summaries
* Action items extraction
* Risk and blocker identification
* Organized planning dashboards

## Key Learnings

* How Custom Skills automate repetitive workflows
* Converting unstructured notes into structured insights
* Reusability of AI workflows in Claude
* Improving productivity using AI-based planning tools
